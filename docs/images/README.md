## Guidelines

1. **Format**: PNG with transparency where appropriate
2. **Resolution**: At least 2x for retina displays
3. **Style**: Match the application's dark theme
4. **Content**: Show realistic use cases
5. **Privacy**: Ensure no personal data is visible

## How to Add Screenshots

1. Take screenshots of the application
2. Crop and resize as needed
3. Optimize for web (use tools like TinyPNG)
4. Place files in this directory
5. Update README.md to reference the new files

## Tools for Screenshots

- **Windows**: Snipping Tool, ShareX
- **macOS**: Cmd+Shift+4, CleanShot X
- **Linux**: Flameshot, Shutter

For web-optimized images, use:
