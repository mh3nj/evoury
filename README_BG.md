## Относно

Evoury е мощен, офлайн-първи креативен мениджър на активи, изграден с Tauri, React и Rust. Проектиран за креативни професионалисти, които се нуждаят от бърз и надежден достъп до техните дигитални активи без компромиси в производителността или поверителността.

### Защо Evoury?

- **Офлайн-първи**: Вашите активи остават на вашата машина. Няма облак зависимост.
- **Мълниеносен**: Изграден с Rust за производителност, която мащабира с вашата библиотека.
- **Модулна архитектура**: Повече от 40 специализирани crate за максимална гъвкавост.
- **Красив интерфейс**: Модерен, отзивчив интерфейс изграден с React и Tailwind CSS.

## Функции

### Основен Мотор

- **Мулти-формат поддръжка**: Изображения, видеа, 3D модели, аудио, документи и още
- **Интелигентно сдвояване**: Автоматично групира свързаните файлове
- **Машина на състоянията**: Проследява активите от откриване до архивиране
- **Събитийно-управляема архитектура**: Разединена комуникация чрез събитиен шин

### Управление на Библиотеки

- **Разширен скенер**: Пълно, инкрементално, файлово-специфично и фоново сканиране
- **Наблюдател на файловата система**: Синхронизация в реално време без ръчно обновяване
- **Метаданни pipeline**: Автоматично извличане, нормализиране, валидиране и кеширане
- **Откриване на дубликати**: SHA256, перцептуално хеширане и базирано на метаданни

### Търсене и Организиране

- **Постоянен индекс за търсене**: Мълниеносно пълнотекстово търсене с FTS5
- **Интелигентни колекции**: Базирани на правила, автоматично обновяващи се колекции
- **Разширен език за заявки**: Филтри по тип, етикет, оценка, дата, камера и още
- **Профили за търсене**: Запазвайте и превключвайте между конфигурациите за търсене

### Система за Работно Пространство

- **Постоянни работни пространства**: Помни цялото състояние на сесията
- **Няколко работни пространства**: Превключвайте между различни контексти на проекти
- **Работни станции**: Предварително конфигурирани оформления с инструменти, клавишни комбинации и теми
- **Закачащи се панели**: Напълно персонализируем мотор за оформление

### Здраве и Поддръжка

- **Здравен мотор**: Проверява целостта на файловата система, базата данни, кеша и метаданните
- **Автоматичен ремонт**: Един клик ремонт за открити проблеми
- **Възстановяване на сесия**: Възстановява работното пространство след неочаквани изключвания
- **Режим на сън**: Минимално използване на ресурси в бездействие

## Инсталация

### Предварителни Изисквания

- [Rust](https://www.rust-lang.org/tools/install) (последна стабилна версия)
- [Node.js](https://nodejs.org/) (v18 или по-нова)
- [pnpm](https://pnpm.io/) (v8 или по-нова)

### Изтегляне

Изтеглете последната версия от страницата [Releases](https://github.com/mh3nj/evoury/releases).

### Компилиране от Източник

```bash
# Клонирайте хранилището
git clone https://github.com/mh3nj/evoury.git
cd evoury

# Инсталирайте зависимостите
pnpm install

# Стартирайте сървъра за разработка
pnpm tauri dev

# Компирайте за продукция
pnpm tauri build
```

## Разработка

### Налични Команди

```bash
# Разработка
pnpm dev              # Стартирайте Vite сървъра за разработка
pnpm tauri dev        # Стартирайте Tauri в режим разработка

# Компиране
pnpm build            # Компирайте frontend-а
pnpm tauri build      # Компирайте Tauri приложението за продукция

# Тестове
pnpm test             # Стартирайте frontend тестовете
cargo test            # Стартирайте Rust тестовете

# Lint
pnpm lint             # Стартирайте ESLint
cargo clippy          # Стартирайте Clippy

# Форматиране
pnpm format           # Форматирайте frontend кода
cargo fmt             # Форматирайте Rust кода
```

## Технологичен Стек

### Бекенд

- **Rust** - Системен език за програмиране
- **Tauri** - Фреймуорк за десктоп приложения
- **SQLite** - Локална база данни
- **Crossbeam** - Праймитиви за конкурентност

### Фронтенд

- **React** - UI библиотека
- **TypeScript** - Типобезопасен JavaScript
- **Tailwind CSS** - Utility-first CSS фреймуорк
- **Zustand** - Управление на състоянието
- **Vite** - Инструмент за изграждане и сървър за разработка
