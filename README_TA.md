## பற்றி

Evoury ஒரு சக்திவாய்ந்த, ஆஃப்லைன்-முதல் படைப்பாற்றல் சொத்து மேலாளர் ஆகும், இது Tauri, React மற்றும் Rust மூலம் உருவாக்கப்பட்டது. செயல்திறன் அல்லது தனியுரிமையை சமரசம் செய்யாமல், அவர்களின் டிஜிட்டல் சொத்துகளுக்கு விரைவான மற்றும் நம்பகமான அணுகலை தேவைப்படும் படைப்பாற்றல் தொழில் வல்லுநர்களுக்கு வடிவமைக்கப்பட்டுள்ளது.

### ஏன் Evoury?

- **ஆஃப்லைன்-முதல்**: உங்கள் சொத்துகள் உங்கள் இயந்திரத்திலேயே உள்ளன. கிளவுட் சார்பு இல்லை.
- **மின்னல் வேகமாக**: Rust மூலம் உருவாக்கப்பட்டது, உங்கள் நூலகத்துடன் அளவிடும் செயல்திறன்.
- **மாட்யூலர் கட்டமைப்பு**: அதிகபட்ச நெகிழ்வுத்தன்மைக்காக 40+ நிபுணத்துவ கிரேட்கள்.
- **அழகான UI**: React மற்றும் Tailwind CSS மூலம் உருவாக்கப்பட்ட நவீன, பதிலளிக்கும் இடைமுகம்.

## அம்சங்கள்

### மைய இயந்திரம்

- **பல வடிவ ஆதரவு**: படங்கள், வீடியோக்கள், 3D மாதிரிகள், ஆடியோ, ஆவணங்கள் மற்றும் பல
- **ஸ்மார்ட் இணைப்பு**: தொடர்புடைய கோப்புகளை தானாக குழுவாக்குகிறது
- **சொத்து நிலை இயந்திரம்**: கண்டறிதல் முதல் காப்பகப்படுத்தல் வரை சொத்துகளை கண்காணிக்கிறது
- **நிகழ்வு-சார்ந்த கட்டமைப்பு**: நிகழ்வு பஸ் மூலம் பிரிக்கப்பட்ட தகவல்தொடர்பு

### நூலக மேலாண்மை

- **மேம்பட்ட ஸ்கேனர்**: முழு, தொடர்ச்சியான, கோப்புறை-குறிப்பிட்ட மற்றும் பின்னணி ஸ்கேனிங் பயன்முறைகள்
- **கோப்பு முறைமை கண்காணிப்பாளர்**: கைமுறை புதுப்பிப்பு இல்லாமல் நிகழ்நேர ஒத்திசைவு
- **மெட்டாடேடா குழாய்**: தானியங்கு பிரித்தெடுத்தல், இயல்பாக்கல், சரிபார்ப்பு மற்றும் தற்காலிக சேமிப்பு
- **நகல் கண்டறிதல்**: SHA256, உணர்வு ஹாஷ் மற்றும் மெட்டாடேடா அடிப்படையிலான

### தேடல் மற்றும் ஒழுங்குபடுத்தல்

- **நிலையான தேடல் குறியீடு**: FTS5 உடன் மின்னல் வேகமான முழு உரை தேடல்
- **ஸ்மார்ட் தொகுப்புகள்**: விதிகள் அடிப்படையிலான தானியங்கு புதுப்பிக்கும் தொகுப்புகள்
- **மேம்பட்ட வினவல் மொழி**: வகை, குறிச்சொல், மதிப்பீடு, தேதி, கேமரா போன்றவற்றின் அடிப்படையில் வடிகட்டிகள்
- **தேடல் சுயவிவரங்கள்**: தேடல் அமைவுகளுக்கு இடையில் சேமிக்கவும் மாற்றவும்

### பணியிட அமைப்பு

- **நிலையான பணியிடங்கள்**: முழு அமர்வு நிலையை நினைவில் கொள்கிறது
- **பல பணியிடங்கள்**: வெவ்வேறு திட்ட சூழல்களுக்கு இடையில் மாற்றவும்
- **பணிநிலையங்கள்**: கருவிகள், குறுக்குவழிகள் மற்றும் கருப்பொருள்களுடன் முன்கட்டமைக்கப்பட்ட தளவமைப்புகள்
- **கப்பல்தள குழுக்கள்**: முழுமையாக தனிப்பயனாக்கக்கூடிய தளவமைப்பு இயந்திரம்

### ஆரோக்கியம் மற்றும் பராமரிப்பு

- **ஆரோக்கிய இயந்திரம்**: கோப்பு முறைமை, தரவுத்தளம், தற்காலிக சேமிப்பு மற்றும் மெட்டாடேடா ஒருமைப்பாட்டை சரிபார்க்கிறது
- **தானியங்கு பழுதுபார்த்தல்**: கண்டறியப்பட்ட சிக்கல்களுக்கு ஒரே கிளிக்கில் பழுதுபார்த்தல்
- **அமர்வு மீட்பு**: எதிர்பாராத முடிவுகளுக்குப் பிறகு பணியிடத்தை மீட்டெடுக்கிறது
- **தூக்க பயன்முறை**: செயலற்ற நேரத்தில் குறைந்தபட்ச வள பயன்பாடு

## நிறுவல்

### முன்நிபந்தனைகள்

- [Rust](https://www.rust-lang.org/tools/install) (சமீபத்திய நிலையான பதிப்பு)
- [Node.js](https://nodejs.org/) (v18 அல்லது அதற்கு மேல்)
- [pnpm](https://pnpm.io/) (v8 அல்லது அதற்கு மேல்)

### பதிவிறக்கம்

[Releases](https://github.com/mh3nj/evoury/releases) பக்கத்திலிருந்து சமீபத்திய பதிப்பை பதிவிறக்கவும்.

### மூலத்திலிருந்து உருவாக்குதல்

```bash
# களஞ்சியத்தை குளோன் செய்யுங்கள்
git clone https://github.com/mh3nj/evoury.git
cd evoury

# சார்புநிலைகளை நிறுவுங்கள்
pnpm install

# உருவாக்க சேவையகத்தைத் தொடங்குங்கள்
pnpm tauri dev

# உற்பத்திக்காக உருவாக்குங்கள்
pnpm tauri build
```

## உருவாக்கம்

### கிடைக்கும் கட்டளைகள்

```bash
# உருவாக்கம்
pnpm dev              # Vite உருவாக்க சேவையகத்தைத் தொடங்குங்கள்
pnpm tauri dev        # உருவாக்க பயன்முறையில் Tauri ஐ தொடங்குங்கள்

# உருவாக்கம்
pnpm build            # முன்பக்கத்தை உருவாக்குங்கள்
pnpm tauri build      # உற்பத்திக்காக Tauri பயன்பாட்டை உருவாக்குங்கள்

# சோதனைகள்
pnpm test             # முன்பக்க சோதனைகளை இயக்குங்கள்
cargo test            # Rust சோதனைகளை இயக்குங்கள்

# லின்ட்
pnpm lint             # ESLint ஐ இயக்குங்கள்
cargo clippy          # Clippy ஐ இயக்குங்கள்

# வடிவமைத்தல்
pnpm format           # முன்பக்க குறியீட்டை வடிவமையுங்கள்
cargo fmt             # Rust குறியீட்டை வடிவமையுங்கள்
```

## தொழில்நுட்ப ஸ்டாக்

### பின்பக்கம்

- **Rust** - கணினி நிரலாக்க மொழி
- **Tauri** - டெஸ்க்டாப் பயன்பாட்டு கட்டமைப்பு
- **SQLite** - உள்ளூர் தரவுத்தளம்
- **Crossbeam** - இணை நிரலாக்க முதன்மைகள்

### முன்பக்கம்

- **React** - UI நூலகம்
- **TypeScript** - வகை-பாதுகாப்பான JavaScript
- **Tailwind CSS** - பயன்பாட்டு-முதல் CSS கட்டமைப்பு
- **Zustand** - நிலை மேலாண்மை
- **Vite** - உருவாக்க கருவி மற்றும் உருவாக்க சேவையகம்
