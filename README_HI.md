## के बारे में

Evoury एक शक्तिशाली, ऑफ़लाइन-फ़र्स्ट क्रिएटिव एसेट मैनेजर है जो Tauri, React और Rust से बनाया गया है। यह उन क्रिएटिव पेशेवरों के लिए डिज़ाइन किया गया है जिन्हें प्रदर्शन या गोपनीयता से समझौता किए बिना अपने डिजिटल एसेट्स तक तेज़ और विश्वसनीय पहुंच की आवश्यकता है।

### क्यों Evoury?

- **ऑफ़लाइन-फ़र्स्ट**: आपके एसेट्स आपके मशीन पर रहते हैं। कोई क्लाउड निर्भरता नहीं।
- **ब्लेज़िंग फ़ास्ट**: Rust से बनाया गया है जो आपकी लाइब्रेरी के साथ स्केल होता है।
- **मॉड्यूलर आर्किटेक्चर**: अधिकतम लचीलेपन के लिए 40+ विशिष्ट क्रेट्स।
- **सुंदर UI**: React और Tailwind CSS से बना आधुनिक, रिस्पॉन्सिव इंटरफ़ेस।

## विशेषताएं

### कोर इंजन

- **मल्टी-फ़ॉर्मेट सपोर्ट**: इमेज, वीडियो, 3D मॉडल, ऑडियो, दस्तावेज़ और बहुत कुछ
- **स्मार्ट एसेट पेयरिंग**: संबंधित फ़ाइलों को स्वचालित रूप से ग्रुप करता है
- **एसेट स्टेट मशीन**: खोज से लेकर आर्काइव तक एसेट्स को ट्रैक करता है
- **इवेंट-ड्रिवन आर्किटेक्चर**: इवेंट बस के माध्यम से अलग-अलग सेवाओं का संचार

### लाइब्रेरी प्रबंधन

- **उन्नत स्कैनर**: फ़ुल, इंक्रीमेंटल, फ़ोल्डर-स्पेसिफिक और बैकग्राउंड स्कैन मोड
- **फ़ाइलसिस्टम वॉचर**: बिना मैनुअल रीफ़्रेश के रीयल-टाइम सिंक
- **मेटाडेटा पाइपलाइन**: स्वचालित एक्सट्रैक्शन, नॉर्मलाइज़ेशन, वैलिडेशन और कैशिंग
- **डुप्लिकेट डिटेक्शन**: SHA256, पर्सेप्चुअल हैश और मेटाडेटा-आधारित

### खोज और व्यवस्था

- **पर्सिस्टेंट सर्च इंडेक्स**: FTS5 के साथ लाइटनिंग-फ़ास्ट फ़ुल-टेक्स्ट सर्च
- **स्मार्ट कलेक्शन्स**: रूल-आधारित ऑटो-अपडेटिंग कलेक्शन्स
- **एडवांस्ड क्वेरी लैंग्वेज**: टाइप, टैग, रेटिंग, डेटा, कैमरा आदि द्वारा फ़िल्टर
- **सर्च प्रोफ़ाइल्स**: सर्च कॉन्फ़िगरेशन को सेव करें और स्विच करें

### वर्कस्पेस सिस्टम

- **पर्सिस्टेंट वर्कस्पेस**: पूरे सेशन स्टेट को याद रखता है
- **मल्टीपल वर्कस्पेस**: अलग-अलग प्रोजेक्ट कॉन्टेक्स्ट के बीच स्विच करें
- **वर्कस्टेशन्स**: टूल्स, शॉर्टकट्स और थीम्स के साथ प्री-कॉन्फ़िगर्ड लेआउट्स
- **डॉकेबल पैनल्स**: पूरी तरह से कस्टमाइज़ेबल लेआउट इंजन

### हेल्थ और मेंटेनेंस

- **हेल्थ इंजन**: फ़ाइलसिस्टम, डेटाबेस, कैश और मेटाडेटा इंटीग्रिटी चेक
- **ऑटोमैटिक रिपेयर**: डिटेक्ट की गई समस्याओं के लिए वन-क्लिक रिपेयर
- **सेशन रिकवरी**: अनएक्सपेक्टेड शटडाउन के बाद वर्कस्पेस को रीस्टोर करता है
- **स्लीप मोड**: आइडल होने पर न्यूनतम रिसोर्स उपयोग

## इंस्टॉलेशन

### पूर्वापेक्षाएं

- [Rust](https://www.rust-lang.org/tools/install) (नवीनतम स्थिर संस्करण)
- [Node.js](https://nodejs.org/) (v18 या उससे अधिक)
- [pnpm](https://pnpm.io/) (v8 या उससे अधिक)

### डाउनलोड

[Releases](https://github.com/mh3nj/evoury/releases) पेज से नवीनतम संस्करण डाउनलोड करें।

### सोर्स से बिल्ड

```bash
# रिपॉज़िटरी क्लोन करें
git clone https://github.com/mh3nj/evoury.git
cd evoury

# डिपेंडेंसी इंस्टॉल करें
pnpm install

# डेवलपमेंट सर्वर शुरू करें
pnpm tauri dev

# प्रोडक्शन के लिए बिल्ड करें
pnpm tauri build
```

## विकास

### उपलब्ध कमांड्स

```bash
# विकास
pnpm dev              # Vite डेवलपमेंट सर्वर शुरू करें
pnpm tauri dev        # डेवलपमेंट मोड में Tauri शुरू करें

# बिल्ड
pnpm build            # फ़्रंटएंड बिल्ड करें
pnpm tauri build      # प्रोडक्शन के लिए Tauri ऐप बिल्ड करें

# टेस्ट्स
pnpm test             # फ़्रंटएंड टेस्ट्स चलाएं
cargo test            # Rust टेस्ट्स चलाएं

# लिंट
pnpm lint             # ESLint चलाएं
cargo clippy          # Clippy चलाएं

# फ़ॉर्मेटिंग
pnpm format           # फ़्रंटएंड कोड फ़ॉर्मेट करें
cargo fmt             # Rust कोड फ़ॉर्मेट करें
```

## टेक स्टैक

### बैकएंड

- **Rust** — सिस्टम प्रोग्रामिंग भाषा
- **Tauri** — डेस्कटॉप ऐप फ़्रेमवर्क
- **SQLite** — लोकल डेटाबेस
- **Crossbeam** — कॉन्करेंसी प्रिमिटिव्स

### फ़्रंटएंड

- **React** — UI लाइब्रेरी
- **TypeScript** — टाइप-सेफ़ JavaScript
- **Tailwind CSS** — यूटिलिटी-फ़र्स्ट CSS फ़्रेमवर्क
- **Zustand** — स्टेट मैनेजमेंट
- **Vite** — बिल्ड टूल और डेवलपमेंट सर्वर
