## વિશે

Evoury એક શક્તિશાળી, ઓફલાઇન-પહેલું સર્જનાત્મક સંપત્તિ મેનેજર છે જે Tauri, React અને Rust સાથે બનાવવામાં આવ્યું છે. સર્જનાત્મક વ્યાવસાયિકો માટે રચાયેલ છે જેમને પ્રદર્શન અથવા ગોપનીયતા સાથે સમાધાન કર્યા વિના તેમના ડિજિટલ સંપત્તિ સુધી ઝડપી અને વિશ્વસનીય ઍક્સેસની જરૂર છે.

### શા માટે Evoury?

- **ઓફલાઇન-પહેલું**: તમારી સંપત્તિ તમારા મશીન પર રહે છે. કોઈ ક્લાઉડ આશ્રિતતા નથી.
- **વીજળી ઝડપી**: તમારી લાઇબ્રેરી સાથે સ્કેલ થતા પ્રદર્શન માટે Rust સાથે બનાવેલ.
- **મોડ્યુલર આર્કિટેક્ચર**: મહત્તમ લવચીંટા માટે 40+ વિશેષિત ક્રેટ.
- **સુંદર UI**: React અને Tailwind CSS સાથે બનાવેલ આધુનિક, પ્રતિસાદી ઇન્ટરફેસ.

## સુવિધાઓ

### કોર એન્જિન

- **મલ્ટી-ફોર્મેટ સપોર્ટ**: છબીઓ, વિડિયો, 3D મોડલ્સ, ઓડિયો, દસ્તાવેજો અને ઘણું બધું
- **સ્માર્ટ પેરિંગ**: સંબંધિત ફાઈલો આપમેળે જૂથ બનાવે છે
- **સંપત્તિ સ્ટેટ મશીન**: શોધથી આર્કાઇવ સુધી સંપત્તિ ટ્રૅક કરે છે
- **ઇવેન્ટ-ડ્રિવન આર્કિટેક્ચર**: ઇવેન્ટ બસ દ્વારા વિભાજિત સંદેશાવહાલો

### લાઇબ્રેરી વ્યવસ્થાપન

- **અદ્યતન સ્કેનર**: સંપૂર્ણ, ઇન્ક્રીમેન્ટલ, ફોલ્ડર-વિશિષ્ટ અને બેકગ્રાઉન્ડ સ્કેનિંગ મોડ
- **ફાઈલસિસ્ટમ વોચર**: મેન્યુઅલ રીફ્રેશ વિના રીઅલ-ટાઇમ સિંક
- **મેટાડેટા પાઇપલાઇન**: આપમેળે કાઢવું, નોર્મલાઇઝેશન, માન્યતા અને કેશિંગ
- **ડુપ્લિકેટ શોધ**: SHA256, પર્સેપ્ચ્યુઅલ હેશ અને મેટાડેટા-આધારિત

### શોધ અને સંગઠન

- **સ્થાયી શોધ ઇન્ડેક્સ**: FTS5 સાથે વીજળી ઝડપી સંપૂર્ણ-ટેક્સ્ટ શોધ
- **સ્માર્ટ કલેક્શન્સ**: નિયમ-આધારિત આપમેળે અપડેટ થતા કલેક્શન્સ
- **અદ્યતન ક્વેરી ભાષા**: પ્રકાર, ટેગ, રેટિંગ, તારીખ, કેમેરા વગેરે દ્વારા ફિલ્ટર
- **શોધ પ્રોફાઇલ્સ**: શોધ કોન્ફિગરેશન વચ્ચે સાચવો અને સ્વિચ કરો

### વર્કસ્પેસ સિસ્ટમ

- **સ્થાયી વર્કસ્પેસ**: સંપૂર્ણ સેશન સ્ટેટ યાદ રાખે છે
- **બહુવિધ વર્કસ્પેસ**: વિવિધ પ્રોજેક્ટ સંદર્ભો વચ્ચે સ્વિચ કરો
- **વર્કસ્ટેશન્સ**: ટૂલ્સ, શોર્ટકટ્સ અને થીમ્સ સાથે પૂર્વ-કોન્ફિગર કરેલ લેઆઉટ્સ
- **ડોક કરી શકાય તેવા પેનલ્સ**: સંપૂર્ણપણે કસ્ટમાઇઝ કરી શકાય તેવું લેઆઉટ એન્જિન

### આરોગ્ય અને જાળવણી

- **આરોગ્ય એન્જિન**: ફાઈલસિસ્ટમ, ડેટાબેસ, કેશ અને મેટાડેટાની સંપૂર્ણતા તપાસે છે
- **આપમેળે સમારકામ**: શોધાયેલ સમસ્યાઓ માટે એક ક્લિક સમારકામ
- **સેશન રિકવરી**: અનપેક્ષિત બંધ થયા પછી વર્કસ્પેસ પુનઃસ્થાપિત કરે છે
- **સ્લીપ મોડ**: નિષ્ક્રિય સમયે ન્યૂનતમ સંસાધન ઉપયોગ

## સ્થાપન

### પૂર્વશરતો

- [Rust](https://www.rust-lang.org/tools/install) (નવીનતમ સ્થિર આવૃત્તિ)
- [Node.js](https://nodejs.org/) (v18 અથવા વધુ)
- [pnpm](https://pnpm.io/) (v8 અથવા વધુ)

### ડાઉનલોડ

[Releases](https://github.com/mh3nj/evoury/releases) પેજ પરથી નવીનતમ આવૃત્તિ ડાઉનલોડ કરો.

### સોર્સ માંથી બિલ્ડ

```bash
# રિપોઝીટરી ક્લોન કરો
git clone https://github.com/mh3nj/evoury.git
cd evoury

# ડિપેન્ડન્સી સ્થાપિત કરો
pnpm install

# વિકાસ સર્વર શરૂ કરો
pnpm tauri dev

# ઉત્પાદન માટે બિલ્ડ
pnpm tauri build
```

## વિકાસ

### ઉપલબ્ધ કમાન્ડ્સ

```bash
# વિકાસ
pnpm dev              # Vite વિકાસ સર્વર શરૂ કરો
pnpm tauri dev        # વિકાસ મોડમાં Tauri શરૂ કરો

# બિલ્ડ
pnpm build            # ફ્રન્ટએન્ડ બિલ્ડ કરો
pnpm tauri build      # ઉત્પાદન માટે Tauri એપ બિલ્ડ કરો

# ટેસ્ટ્સ
pnpm test             # ફ્રન્ટએન્ડ ટેસ્ટ્સ ચલાવો
cargo test            # Rust ટેસ્ટ્સ ચલાવો

# લિન્ટ
pnpm lint             # ESLint ચલાવો
cargo clippy          # Clippy ચલાવો

# ફોર્મેટિંગ
pnpm format           # ફ્રન્ટએન્ડ કોડ ફોર્મેટ કરો
cargo fmt             # Rust કોડ ફોર્મેટ કરો
```

## ટેક સ્ટેક

### બેકએન્ડ

- **Rust** - સિસ્ટમ પ્રોગ્રામિંગ ભાષા
- **Tauri** - ડેસ્કટોપ એપ ફ્રેમવર્ક
- **SQLite** - સ્થાનિક ડેટાબેસ
- **Crossbeam** - સમાંતર પ્રોગ્રામિંગ પ્રિમિટિવ્સ

### ફ્રન્ટએન્ડ

- **React** - UI લાઇબ્રેરી
- **TypeScript** - ટાઇપ-સેફ JavaScript
- **Tailwind CSS** - યુટિલિટી-ફર્સ્ટ CSS ફ્રેમવર્ક
- **Zustand** - સ્ટેટ મેનેજમેન્ટ
- **Vite** - બિલ્ડ ટૂલ અને વિકાસ સર્વર
