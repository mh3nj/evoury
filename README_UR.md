## کے بارے میں

Evoury ایک طاقتور، آف لائن پہلے تخلیقی اثاثوں کا منتظم ہے جو Tauri، React اور Rust سے بنایا گیا ہے۔ تخلیقی پیشہ وران کے لیے ڈیزائن کیا گیا ہے جنہیں اپنے ڈیجیٹل اثاثوں تک تیز اور قابل اعتماد رسائی کی ضرورت ہے بغیر کارکردگی یا رازداری سے سازش کے۔

### کیوں Evoury؟

- **آف لائن پہلے**: آپ کے اثاثے آپ کے مشین پر رہتے ہیں۔ کوئی کلاؤڈ انحصار نہیں۔
- **بجلی کی طرح تیز**: Rust کے ساتھ بنایا گیا تھا جو آپ کی لائبریری کے ساتھ اسکیل ہوتا ہے۔
- **ماڈیولر فن تعمیر**: زیادہ سے زیادہ لچک کے لیے 40+ مخصوص کریٹس۔
- **خوبصورت UI**: React اور Tailwind CSS سے بنایا گیا جدید، ریسپانسو انٹرفیس۔

## خصوصیات

### مرکزی انجین

- **کثیر فارمیٹ سپورٹ**: تصاویر، ویڈیوز، 3D ماڈلز، آڈیو، دستاویزات اور بہت کچھ
- **ذہین جوڑی**: مربوط فائلوں کو خودکار طور پر گروپ کرتا ہے
- **اثاثے کی حالت مشین**: اثاثوں کو دریافت سے آرکائیو تک ٹریک کرتا ہے
- **واقعات سے چلنے والی فن تعمیر**: ایونٹ بس کے ذریعے الگ ٹھیلی کیوں

### لائبریری مینجمنٹ

- **ایڈوانسڈ اسکینر**: مکمل، مسلسل، فولڈر مخصوص اور پس منظر اسکیننگ موڈز
- **فائل سسٹم واچر**: تازہ کاری کے بغیر حقیقی وقت میں مطابقت
- **میٹا ڈیٹا پائپ لائن**: خودکار استخراج، نارملائزیشن، تصدیق اور کیشنگ
- **ڈوپلیکیٹ کا پتہ لگانا**: SHA256، ادراکی ایش اور میٹا ڈیٹا پر مبنی

### تلاش و تنظیم

- **پائیدار تلاش انڈیکس**: FTS5 کے ساتھ بجلی کی طرح تیز مکمل متن تلاش
- **ذہین کلیکشنز**: قواعد پر مبنی خودکار اپ ڈیٹنگ کلیکشنز
- **ایڈوانسڈ کوئری لینگویج**: قسم، ٹیگ، درجہ بندی، تاریخ، کیمرہ وغیرہ کے مطابق فلٹرز
- **تلاش پروفائلز**: تلاش کنفیگریشنز کے درمیان محفوظ کریں اور سوئچ کریں

### ورک اسپیس سسٹم

- **پائیدار ورک اسپیسز**: پورے سیشن کی حالت یاد رکھتا ہے
- **متعدد ورک اسپیسز**: مختلف پروجیکٹ کنٹیکسٹس کے درمیان سوئچ کریں
- **ورک اسٹیشنز**: ٹولز، شارٹ کٹس اور تھیمز کے ساتھ پیش ترتیب شدے لے آؤٹس
- **ڈوک قابل پینل**: مکمل طور پر تخصیص پذیر لے آؤٹ انجین

### صحت اور دیکھ بھال

- **صحت کا انجین**: فائل سسٹم، ڈیٹا بیس، کیش اور میٹا ڈیٹا کی سالمیت کو چیک کرتا ہے
- **خودکار مرمت**: پائی گئی مسائل کے لیے ون کلک مرمت
- **سیشن کی بحالی**: غیر متوقع بندش کے بعد ورک اسپیس کو بحال کرتا ہے
- **سونے کا موڈ**: سست ہونے پر کم سے کم وسائل کا استعمال

## انسٹالیشن

### شرائط

- [Rust](https://www.rust-lang.org/tools/install) (تازہ ترین مستحکم ورژن)
- [Node.js](https://nodejs.org/) (v18 یا اس سے زیادہ)
- [pnpm](https://pnpm.io/) (v8 یا اس سے زیادہ)

### ڈاؤن لوڈ

[Releases](https://github.com/username/evoury/releases) صفحہ سے تازہ ترین ورژن ڈاؤن لوڈ کریں۔

### سورس سے بلڈ

```bash
# ریپو کلون کریں
git clone https://github.com/mh3nj/evoury.git
cd evoury

# انحصارات انسٹال کریں
pnpm install

# ڈیولپمنٹ سرور شروع کریں
pnpm tauri dev

# پروڈکشن کے لیے بلڈ
pnpm tauri build
```

---

## ڈیولپمنٹ

### دستیاب کمانڈیں

```bash
# ڈیولپمنٹ
pnpm dev              # Vite ڈیولپمنٹ سرور شروع کریں
pnpm tauri dev        # ڈیولپمنٹ موڈ میں Tauri شروع کریں

# بلڈ
pnpm build            # فرنٹ اینڈ بلڈ کریں
pnpm tauri build      # پروڈکشن کے لیے Tauri ایپ بلڈ کریں

# ٹیسٹس
pnpm test             # فرنٹ اینڈ ٹیسٹس چلائیں
cargo test            # Rust ٹیسٹس چلائیں

# لِنٹ
pnpm lint             # ESLint چلائیں
cargo clippy          # Clippy چلائیں

# فارمیٹنگ
pnpm format           # فرنٹ اینڈ کوڈ فارمیٹ کریں
cargo fmt             # Rust کوڈ فارمیٹ کریں
```

## ٹیک اسٹیک

### بیک اینڈ

- **Rust** - سسٹم پروگرامنگ زبان
- **Tauri** - ڈیسکٹاپ ایپ فریم ورک

- **Zustand** - حالت کا انتظام
