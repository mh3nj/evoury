## О проекте

Evoury — это мощный оффлайн-менеджер креативных активов, построенный на Tauri, React и Rust. Разработан для креативных профессионалов, которым нужен быстрый и надежный доступ к цифровым активам без компромиссов в производительности и приватности.

### Почему Evoury?

- **Оффлайн**: Ваши активы остаются на вашем компьютере. Без облачных зависимостей.
- **Молниеносная скорость**: Построен на Rust для производительности, масштабируемой с библиотекой.
- **Модульная архитектура**: Более 40 специализированных крейтов для максимальной гибкости.
- **Красивый интерфейс**: Современный, адаптивный интерфейс на React и Tailwind CSS.

## Возможности

### Основной движок

- **Многоформатная поддержка**: Изображения, видео, 3D-модели, аудио, документы и многое другое
- **Умное сопоставление**: Автоматическая группировка связанных файлов
- **Машина состояний**: Отслеживание активов от обнаружения до архивации
- **Событийная архитектура**: Развязанная коммуникация через шину событий

### Управление библиотеками

- **Продвинутый сканер**: Полный, инкрементальный, по папкам и фоновый режимы сканирования
- **Наблюдатель файловой системы**: Синхронизация в реальном времени без ручного обновления
- **Пайплайн метаданных**: Автоматическое извлечение, нормализация, валидация и кеширование
- **Определение дубликатов**: SHA256, перцептуальное хеширование и на основе метаданных

### Поиск и организация

- **Постоянный поисковый индекс**: Молниеносный полнотекстовый поиск с FTS5
- **Умные коллекции**: Правило-ориентированные автоматически обновляемые коллекции
- **Продвинутый язык запросов**: Фильтры по типу, тегу, рейтингу, дате, камере и многому другому
- **Поисковые профили**: Сохраняйте и переключайтесь между конфигурациями поиска

### Система рабочих пространств

- **Постоянные рабочие пространства**: Запоминает всё состояние сессии
- **Несколько рабочих пространств**: Переключение между контекстами проектов
- **Рабочие станции**: Предустановленные макеты с инструментами, горячими клавишами и темами
- **Dockable панели**: Полностью настраиваемый движок макетов

### Здоровье и обслуживание

- **Движок здоровья**: Проверка целостности файловой системы, базы данных, кеша и метаданных
- **Автоматическое восстановление**: Восстановление одним кликом для обнаруженных проблем
- **Восстановление сессии**: Восстановление рабочего пространства после незапланированных выключений
- **Режим сна**: Минимальное использование ресурсов в простое

## Установка

### Требования

- [Rust](https://www.rust-lang.org/tools/install) (последняя стабильная версия)
- [Node.js](https://nodejs.org/) (v18 или выше)
- [pnpm](https://pnpm.io/) (v8 или выше)

### Загрузка

Загрузите последнюю версию со страницы [Releases](https://github.com/mh3nj/evoury/releases).

### Сборка из исходников

```bash
# Клонировать репозиторий
git clone https://github.com/mh3nj/evoury.git
cd evoury

# Установить зависимости
pnpm install

# Запустить сервер разработки
pnpm tauri dev

# Собрать для продакшена
pnpm tauri build
```

## Разработка

### Доступные команды

```bash
# Разработка
pnpm dev              # Запустить сервер Vite
pnpm tauri dev        # Запустить Tauri в режиме разработки

# Сборка
pnpm build            # Собрать фронтенд
pnpm tauri build      # Собрать приложение Tauri

# Тесты
pnpm test             # Запустить тесты фронтенда
cargo test            # Запустить тесты Rust

# Линт
pnpm lint             # Запустить ESLint
cargo clippy          # Запустить Clippy

# Форматирование
pnpm format           # Отформатировать код фронтенда
cargo fmt             # Отформатировать код Rust
```

## Технологический стек

### Бэкенд

- **Rust** — язык системного программирования
- **Tauri** — фреймворк десктопных приложений
- **SQLite** — локальная база данных
- **Crossbeam** — примитивы конкурентного программирования

### Фронтенд

- **React** — библиотека UI
- **TypeScript** — типизированный JavaScript
- **Tailwind CSS** — утилитарный CSS-фреймворк
- **Zustand** — управление состоянием
- **Vite** — инструмент сборки и сервер разработки
