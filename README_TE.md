## గురించి

Evoury అనేది Tauri, React మరియు Rust తో నిర్మించబడిన శక్తివంతమైన, ఆఫ్‌లైన్-మొదటి సృజనాత్మక ఆస్తి మేనేజర్. పనితీరు లేదా గోప్యతను రాజీ చేయకుండా వారి డిజిటల్ ఆస్తులకు వేగవంతమైన మరియు నమ్మదగిన యాక్సెస్ అవసరమైన సృజనాత్మక వృత్తిపరుల కోసం రూపొందించబడింది.

### ఎందుకు Evoury?

- **ఆఫ్‌లైన్-మొదటి**: మీ ఆస్తులు మీ మెషీన్‌లోనే ఉంటాయి. క్లౌడ్ ఆధారితం లేదు.
- **మెరుపు వేగంగా**: మీ లైబ్రెరీతో స్కేల్ అయ్యే పనితీరు కోసం Rust తో నిర్మించబడింది.
- **మాడ్యులర్ ఆర్కిటెక్చర్**: గరిష్ట వశ్యత కోసం 40+ ప్రత్యేక క్రేట్‌లు.
- **అందమైన UI**: React మరియు Tailwind CSS తో నిర్మించబడిన ఆధునిక, రెస్పాన్సివ్ ఇంటర్‌ఫేస్.

## లక్షణాలు

### కోర్ ఇంజన్

- **మల్టీ-ఫార్మాట్ సపోర్ట్**: చిత్రాలు, వీడియోలు, 3D మోడల్స్, ఆడియో, డాక్యుమెంట్లు మరియు మరిన్ని
- **స్మార్ట్ పేరింగ్**: సంబంధిత ఫైల్‌లను స్వయంచాలకంగా గ్రూప్ చేస్తుంది
- **ఆస్తి స్థితి మెషీన్**: ఆవిష్కరణ నుండి ఆర్కైవల్ వరకు ఆస్తులను ట్రాక్ చేస్తుంది
- **ఈవెంట్-డ్రివెన్ ఆర్కిటెక్చర్**: ఈవెంట్ బస్ ద్వారా విచ్ఛిన్న కమ్యూనికేషన్

### లైబ్రెరీ నిర్వహణ

- **అధునాతన స్కానర్**: పూర్తి, క్రమంగా, ఫోల్డర్-నిర్దిష్ట మరియు బ్యాక్‌గ్రౌండ్ స్కానింగ్ మోడ్‌లు
- **ఫైల్‌సిస్టం వాచర్**: మాన్యువల్ రీఫ్రెష్ లేకుండా రియల్-టైమ్ సింక్
- **మెటాడేటా పైప్‌లైన్**: స్వయంచాలక ఎక్స్‌ట్రాక్షన్, నార్మలైజేషన్, వెరిఫికేషన్ మరియు కాషింగ్
- **డూప్లికేట్ డిటెక్షన్**: SHA256, పెర్సెప్చువల్ హాష్ మరియు మెటాడేటా-ఆధారిత

### శోధన మరియు నిర్వహణ

- **శాశ్వత శోధన సూచిక**: FTS5 తో మెరుపు వేగంగా పూర్తి వచన శోధన
- **స్మార్ట్ సేకరణలు**: నియమ-ఆధారిత స్వయంచాలక నవీకరణ సేకరణలు
- **అధునాతన ప్రశ్న భాష**: రకం, ట్యాగ్, రేటింగ్, తేదీ, కెమెరా మొదలైన వాటి ఆధారంగా ఫిల్టర్‌లు
- **శోధన ప్రొఫైల్స్**: శోధన కాన్ఫిగరేషన్ల మధ్య సేవ్ చేయండి మరియు మారండి

### వర్క్‌స్పేస్ సిస్టమ్

- **శాశ్వత వర్క్‌స్పేస్‌లు**: మొత్తం సెషన్ స్థితిని గుర్తుంచుకుంటుంది
- **బహుళ వర్క్‌స్పేస్‌లు**: విభిన్న ప్రాజెక్ట్ సందర్భాల మధ్య మారండి
- **వర్క్‌స్టేషన్లు**: సాధనాలు, షార్ట్‌కట్‌లు మరియు థీమ్‌లతో ముందే కాన్ఫిగర్ చేయబడిన లేఅవుట్‌లు
- **డాక్ చేయగల ప్యానెల్స్**: పూర్తిగా అనుకూలీకరించగల లేఅవుట్ ఇంజన్

### ఆరోగ్యం మరియు నిర్వహణ

- **ఆరోగ్య ఇంజన్**: ఫైల్‌సిస్టం, డేటాబేస్, కాష్ మరియు మెటాడేటా సమగ్రతను తనిఖీ చేస్తుంది
- **స్వయంచాలక మరమ్మత్తు**: గుర్తించబడిన సమస్యల కోసం ఒక్క క్లిక్ మరమ్మత్తు
- **సెషన్ రికవరీ**: అనూహ్య మూసివేతల తర్వాత వర్క్‌స్పేస్‌ను పునరుద్ధరిస్తుంది
- **నిద్ర మోడ్**: నిష్క్రియ సమయంలో కనీస వనరుల వినియోగం

## ఇన్‌స్టాలేషన్

### ముందస్తు అవసరాలు

- [Rust](https://www.rust-lang.org/tools/install) (తాజా స్థిరమైన వెర్షన్)
- [Node.js](https://nodejs.org/) (v18 లేదా అంతకంటే ఎక్కువ)
- [pnpm](https://pnpm.io/) (v8 లేదా అంతకంటే ఎక్కువ)

### డౌన్‌లోడ్

[Releases](https://github.com/mh3nj/evoury/releases) పేజీ నుండి తాజా వెర్షన్‌ను డౌన్‌లోడ్ చేయండి.

### సోర్స్ నుండి బిల్డ్

```bash
# రిపోజిటరీని క్లోన్ చేయండి
git clone https://github.com/mh3nj/evoury.git
cd evoury

# డిపెండెన్సీలను ఇన్‌స్టాల్ చేయండి
pnpm install

# అభివృద్ధి సేవికను ప్రారంభించండి
pnpm tauri dev

# ఉత్పత్తి కోసం బిల్డ్ చేయండి
pnpm tauri build
```

## అభివృద్ధి

### అందుబాటులో ఉన్న ఆదేశాలు

```bash
# అభివృద్ధి
pnpm dev              # Vite అభివృద్ధి సేవికను ప్రారంభించండి
pnpm tauri dev        # అభివృద్ధి మోడ్‌లో Tauri ని ప్రారంభించండి

# బిల్డ్
pnpm build            # ఫ్రంట్‌ఎండ్‌ను బిల్డ్ చేయండి
pnpm tauri build      # ఉత్పత్తి కోసం Tauri యాప్‌ను బిల్డ్ చేయండి

# పరీక్షలు
pnpm test             # ఫ్రంట్‌ఎండ్ పరీక్షలను నడపండి
cargo test            # Rust పరీక్షలను నడపండి

# లింట్
pnpm lint             # ESLint ని నడపండి
cargo clippy          # Clippy ని నడపండి

# ఫార్మాటింగ్
pnpm format           # ఫ్రంట్‌ఎండ్ కోడ్‌ను ఫార్మాట్ చేయండి
cargo fmt             # Rust కోడ్‌ను ఫార్మాట్ చేయండి
```

## టెక్ స్టాక్

### బ్యాక్‌ఎండ్

- **Rust** - సిస్టం ప్రోగ్రామింగ్ భాష
- **Tauri** - డెస్క్‌టాప్ యాప్ ఫ్రేమ్‌వర్క్
- **SQLite** - స్థానిక డేటాబేస్
- **Crossbeam** - సమాంతర ప్రోగ్రామింగ్ ప్రాథమికాలు

### ఫ్రంట్‌ఎండ్

- **React** - UI లైబ్రెరీ
- **TypeScript** - టైప్-సేఫ్ JavaScript
- **Tailwind CSS** - యూటిలిటీ-ఫస్ట్ CSS ఫ్రేమ్‌వర్క్
- **Zustand** - స్థితి నిర్వహణ
- **Vite** - బిల్డ్ టూల్ మరియు అభివృద్ధి సేవిక
