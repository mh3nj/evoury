## সম্পর্কে

Evoury একটি শক্তিশালী, অফলাইন-প্রথম সৃজনশীল সম্পদ ম্যানেজার যা Tauri, React এবং Rust দিয়ে তৈরি। সৃজনশীল পেশাদারদের জন্য ডিজাইন করা হয়েছে যাদের তাদের ডিজিটাল সম্পদে দ্রুত এবং নির্ভরযোগ্য প্রবেশের প্রয়োজন কর্মদক্ষতা বা গোপনীয়তায় আপস ছাড়া।

### কেন Evoury?

- **অফলাইন-প্রথম**: আপনার সম্পদ আপনার মেশিনে থাকে। কোনো ক্লাউড নির্ভরতা নেই।
- **বিদ্যুৎ-দ্রুত**: Rust দিয়ে তৈরি যা আপনার লাইব্রেরির সাথে স্কেল করে।
- **মডুলার আর্কিটেকচার**: সর্বোচ্চ নমনীয়তার জন্য ৪০+ বিশেষায়িত ক্রেট।
- **সুন্দর UI**: React এবং Tailwind CSS দিয়ে তৈরি আধুনিক, রেসপন্সিভ ইন্টারফেস।

## বৈশিষ্ট্য

### কোর ইঞ্জিন

- **মাল্টি-ফরম্যাট সাপোর্ট**: ছবি, ভিডিও, ৩D মডেল, অডিও, ডকুমেন্ট এবং আরও
- **স্মার্ট পেয়ারিং**: সম্পর্কিত ফাইলগুলি স্বয়ংক্রিয়ভাবে গ্রুপ করে
- **সম্পদ অবস্থা মেশিন**: আবিষ্কার থেকে আর্কাইভ পর্যন্ত সম্পদগুলি ট্র্যাক করে
- **ইভেন্ট-ড্রিভেন আর্কিটেকচার**: ইভেন্ট বাসের মাধ্যমে বিচ্ছিন্ন যোগাযোগ

### লাইব্রেরি ব্যবস্থাপনা

- **উন্নত স্ক্যানার**: সম্পূর্ণ, ক্রমবর্ধমান, ফোল্ডার-নির্দিষ্ট এবং ব্যাকগ্রাউন্ড স্ক্যানিং মোড
- **ফাইলসিস্টম ওয়াচার**: ম্যানুয়াল রিফ্রেশ ছাড়াই রিয়েল-টাইম সিঙ্ক
- **মেটাডেটা পাইপলাইন**: স্বয়ংক্রিয় এক্সট্রাকশন, নরমালাইজেশন, ভ্যালিডেশন এবং ক্যাশিং
- **ডুপ্লিকেট সনাক্তকরণ**: SHA256, ধারণামূলক হ্যাশ এবং মেটাডেটা-ভিত্তিক

### অনুসন্ধান এবং সংগঠন

- **স্থায়ী অনুসন্ধান ইন্ডেক্স**: FTS5 দিয়ে বিদ্যুৎ-দ্রুত সম্পূর্ণ-পাঠ্য অনুসন্ধান
- **স্মার্ট সংগ্রহ**: নিয়ম-ভিত্তিক স্বয়ংক্রিয় আপডেটিং সংগ্রহ
- **উন্নত কোয়েরি ভাষা**: ধরন, ট্যাগ, রেটিং, তারিখ, ক্যামেরা ইত্যাদি অনুযায়ী ফিল্টার
- **অনুসন্ধান প্রোফাইল**: অনুসন্ধান কনফিগারেশনের মধ্যে সেভ এবং সুইচ করুন

### ওয়ার্কস্পেস সিস্টেম

- **স্থায়ী ওয়ার্কস্পেস**: পুরো সেশন স্টেট মনে রাখে
- **একাধিক ওয়ার্কস্পেস**: বিভিন্ন প্রজেক্ট প্রসঙ্গের মধ্যে সুইচ করুন
- **ওয়ার্কস্টেশন**: টুল, শর্টকাট এবং থিম সহ পূর্ব-কনফিগার করা লেআউট
- **ডকযোগ্য প্যানেল**: সম্পূর্ণরূপে কাস্টমাইজযোগ্য লেআউট ইঞ্জিন

### স্বাস্থ্য এবং রক্ষণাবেক্ষণ

- **স্বাস্থ্য ইঞ্জিন**: ফাইলসিস্টম, ডাটাবেস, ক্যাশ এবং মেটাডেটার অখণ্ডতা পরীক্ষা করে
- **স্বয়ংক্রিয় মেরামত**: সনাক্তকৃত সমস্যার জন্য এক-ক্লিক মেরামত
- **সেশন পুনরুদ্ধার**: অপ্রত্যাশিত বন্ধের পরে ওয়ার্কস্পেস পুনরুদ্ধার করে
- **ঘুম মোড**: নিষ্ক্রিয় থাকাকালীন ন্যূনতম রিসোর্স ব্যবহার

## ইনস্টলেশন

### পূর্বশর্ত

- [Rust](https://www.rust-lang.org/tools/install) (সর্বশেষ স্থিতিশীল সংস্করণ)
- [Node.js](https://nodejs.org/) (v18 বা তার বেশি)
- [pnpm](https://pnpm.io/) (v8 বা তার বেশি)

### ডাউনলোড

[Releases](https://github.com/mh3nj/evoury/releases) পৃষ্ঠা থেকে সর্বশেষ সংস্করণ ডাউনলোড করুন।

### সোর্স থেকে বিল্ড

```bash
# রিপোজিটরি ক্লোন করুন
git clone https://github.com/mh3nj/evoury.git
cd evoury

# ডিপেন্ডেন্সি ইনস্টল করুন
pnpm install

# ডেভেলপমেন্ট সার্ভার শুরু করুন
pnpm tauri dev

# প্রোডাকশনের জন্য বিল্ড করুন
pnpm tauri build
```

## উন্নয়ন

### উপলব্ধ কমান্ড

```bash
# উন্নয়ন
pnpm dev              # Vite ডেভেলপমেন্ট সার্ভার শুরু করুন
pnpm tauri dev        # ডেভেলপমেন্ট মোডে Tauri শুরু করুন

# বিল্ড
pnpm build            # ফ্রন্টএন্ড বিল্ড করুন
pnpm tauri build      # প্রোডাকশনের জন্য Tauri অ্যাপ বিল্ড করুন

# টেস্ট
pnpm test             # ফ্রন্টএন্ড টেস্ট চালান
cargo test            # Rust টেস্ট চালান

# লিন্ট
pnpm lint             # ESLint চালান
cargo clippy          # Clippy চালান

# ফরম্যাটিং
pnpm format           # ফ্রন্টএন্ড কোড ফরম্যাট করুন
cargo fmt             # Rust কোড ফরম্যাট করুন
```

## টেক স্ট্যাক

### ব্যাকএন্ড

- **Rust** - সিস্টেম প্রোগ্রামিং ভাষা
- **Tauri** - ডেস্কটপ অ্যাপ ফ্রেমওয়ার্ক
- **SQLite** - স্থানীয় ডাটাবেস
- **Crossbeam** - সমান্তরাল প্রোগ্রামিং প্রিমিটিভ

### ফ্রন্টএন্ড

- **React** - UI লাইব্রেরি
- **TypeScript** - টাইপ-সেফ JavaScript
- **Tailwind CSS** - ইউটিলিটি-ফার্স্ট CSS ফ্রেমওয়ার্ক
- **Zustand** - স্টেট ম্যানেজমেন্ট
- **Vite** - বিল্ড টুল এবং ডেভেলপমেন্ট সার্ভার
