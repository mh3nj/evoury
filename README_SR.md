## О пројекту

Evoury је моћан, онлајн-први креативни менаџер ресурса изграђен помоћу Tauri, React и Rust-а. Дизајниран за креативне професионалце који траже брз и поуздан приступ својим дигиталним ресурсима без компромиса у перформансама или приватности.

### Зашто Evoury?

- **Онлајн-први**: Ваши ресурси остају на вашем рачунару. Без облак зависности.
- **Муњевито брз**: Изграђен са Rust-ом за перформансе које скалирају са вашом библиотеком.
- **Модуларна архитектура**: Више од 40 специјализованих crate-ова за максималну флексибилност.
- **Прекрасно интерфејс**: Модеран, респонзивни интерфејс изграђен са React и Tailwind CSS-ом.

## Функције

### Главни Мотор

- **Мулти-формат подршка**: Слике, видеи, 3D модели, звук, документи и више
- **Паметно спаривање**: Аутоматски групише повезане датотеке
- **Стање ресурса**: Прати ресурсе од откривања до архивирања
- **Догађајима управљана архитектура**: Одвојена комуникација преко догађајног магистрале

### Управљање Библиотекама

- **Напредни скенер**: Пуно, инкрементално, мапно специфично и позадинско скенирање
- **Надгледач датотечног система**: Синхронизација у реалном времену без ручног освежавања
- **Метаподатак цевовод**: Аутоматско извлачење, нормализација, валидација и кеширање
- **Откривање дупликата**: SHA256, перцептуално хеширање и метаподацима засновано

### Претраживање и Организација

- **Трајни индекс претраживања**: муњевито брзо претраживање пуног текста са FTS5
- **Паметне колекције**: Правилима засноване аутоматски ажурирајуће колекције
- **Напредни језик упита**: Филтри по типу, ознаци, оцени, датуму, камери и више
- **Профили претраживања**: Сачувајте и пребаците се између конфигурација претраживања

### Систем Радног Простора

- **Трајни радни простори**: Памти целокупно стање сесије
- **Више радних простора**: Пребаците се између различитих контекста пројеката
- **Радне станице**: Унапред конфигурисани распореди са алатима, пречицама и темама
- **Усидрени панели**: Потпуно прилагодљив мотор распореда

### Здравље и Одржавање

- **Здравствени мотор**: Проверава интегритет датотечног система, базе података, кеша и метаподатака
- **Аутоматски поправак**: Поправак једним кликом за откривене проблеме
- **Опоравак сесије**: Враћа радни простор након неочекиваних гашења
- **Режим спавања**: Минимална употреба ресурса у неактивности

## Инсталација

### Предуслови

- [Rust](https://www.rust-lang.org/tools/install) (најновија стабилна верзија)
- [Node.js](https://nodejs.org/) (v18 или новији)
- [pnpm](https://pnpm.io/) (v8 или новији)

### Преузимање

Преузмите најновију верзију са странице [Releases](https://github.com/mh3nj/evoury/releases).

### Градња из Извора

```bash
# Клонирајте репозиторијум
git clone https://github.com/mh3nj/evoury.git
cd evoury

# Инсталирајте зависности
pnpm install

# Покрените развојни сервер
pnpm tauri dev

# Градите за производњу
pnpm tauri build
```

## Развој

### Доступне Наредбе

```bash
# Развој
pnpm dev              # Покрените Vite развојни сервер
pnpm tauri dev        # Покрените Tauri у развојном режиму

# Градња
pnpm build            # Градите frontend
pnpm tauri build      # Градите Tauri апликацију за производњу

# Тестови
pnpm test             # Покрените frontend тестове
cargo test            # Покрените Rust тестове

# Линт
pnpm lint             # Покрените ESLint
cargo clippy          # Покрените Clippy

# Форматирање
pnpm format           # Форматирајте frontend код
cargo fmt             # Форматирајте Rust код
```

## Tech Stack

### Backend

- **Rust** - Системски програмски језик
- **Tauri** - Framework desktop апликација
- **SQLite** - Локална база података
- **Crossbeam** - Примитиви за конкурентност

### Frontend

- **React** - UI библиотека
- **TypeScript** - Типовно безбедан JavaScript
- **Tailwind CSS** - Utility-first CSS framework
- **Zustand** - Управљање стањем
- **Vite** - Алат за градњу и развојни сервер
