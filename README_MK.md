## За Проектот

Evoury е моќен, онлајн-прв креативен менаџер на ресурси изграден со Tauri, React и Rust. Дизајниран за креативни професионалци кои бараат брз и сигурен пристап до нивните дигитални ресурси без компромиси во перформансите или приватноста.

### Зошто Evoury?

- **Онлајн-прв**: Вашите ресурси остануваат на вашиот компјутер. Нема облак зависност.
- **Молскавично брз**: Изграден со Rust за перформанси кои се скалираат со вашата библиотека.
- **Модуларна архитектура**: Повеќе од 40 специјализирани crate-ови за максимална флексибилност.
- **Убав интерфејс**: модерен, одзивен интерфејс изграден со React и Tailwind CSS.

## Функции

### Главен Мотор

- **Мулти-формат поддршка**: Слики, видеа, 3D модели, звук, документи и повеќе
- **Паметно парување**: Автоматски групира поврзани датотеки
- **Состојба на ресурси**: Ги следи ресурсите од откривање до архивирање
- **Настан-управувана архитектура**: Одвоена комуникација преку настан bus

### Управување со Библиотеки

- **Напреден скенер**: Целосно, инкрементално, папка-специфично и позадинско скенирање
- **Набљудувач на датотечен систем**: Синхронизација во реално време без рачно освежување
- **Метаподатоци цевковод**: Автоматско извлекување, нормализација, валидација и кеширање
- **Откривање на дупликати**: SHA256, перцептуално хеширање и метаподатоци базирано

### Пребарување и Организација

- **Траен индекс за пребарување**: Молскавично брзо пребарување на цел текст со FTS5
- **Паметни колекции**: Правила базирани автоматски ажурирачки колекции
- **Напреден јазик за пребарување**: Филтри по тип, ознака, оцена, датум, камера и повеќе
- **Профили за пребарување**: Зачувајте и преминете помеѓу конфигурациите за пребарување

### Систем за Работен Простор

- **Траени работни простори**: Се сеќава на целата состојба на сесијата
- **Повеќе работни простори**: Преминете помеѓу различни контексти на проекти
- **Работни станици**: Предконфигурирани распореди со алатки, кратенки и теми
- **Прикачувачки панели**: Потполно прилагодлив мотор за распоред

### Здравје и одржување

- **Здравствен мотор**: Ја проверува интегритетот на датотечниот систем, базата на податоци, кешот и метаподатоците
- **Автоматско поправање**: Поправање со еден клик за откриени проблеми
- **Опоравување на сесија**: Го враќа работниот простор по неочекувани исклучувања
- **Режим на спиење**: Минимална употреба на ресурси во неактивност

## Инсталација

### Предуслови

- [Rust](https://www.rust-lang.org/tools/install) (најнова стабилна верзија)
- [Node.js](https://nodejs.org/) (v18 или поново)
- [pnpm](https://pnpm.io/) (v8 или поново)

### Преземање

Преземете ја најновата верзија од страницата [Releases](https://github.com/mh3nj/evoury/releases).

### Градење од Извор

```bash
# Клонирајте го репозиториумот
git clone https://github.com/mh3nj/evoury.git
cd evoury

# Инсталирајте ги зависностите
pnpm install

# Стартувајте го развојниот сервер
pnpm tauri dev

# Градете за продукција
pnpm tauri build
```

## Развој

### Достапни Наредби

```bash
# Развој
pnpm dev              # Стартувајте го Vite развојниот сервер
pnpm tauri dev        # Стартувајте го Tauri во развоен режим

# Градење
pnpm build            # Градете frontend
pnpm tauri build      # Градете Tauri апликација за продукција

# Тестови
pnpm test             # Стартувајте frontend тестови
cargo test            # Стартувајте Rust тестови

# Линт
pnpm lint             # Стартувајте ESLint
cargo clippy          # Стартувајте Clippy

# Форматирање
pnpm format           # Форматирајте frontend код
cargo fmt             # Форматирајте Rust код
```

## Tech Stack

### Backend

- **Rust** - Системски програмски јазик
- **Tauri** - Framework за десктоп апликации
- **SQLite** - Локална база на податоци
- **Crossbeam** - Примитиви за конкурентност

### Frontend

- **React** - UI библиотека
- **TypeScript** - Типично безбеден JavaScript
- **Tailwind CSS** - Utility-first CSS framework
- **Zustand** - Управување со состојба
- **Vite** - Алатка за градење и развоен сервер
