## കുറിച്ച്

Evoury ഒരു ശക്തമായ, ഓഫ്‌ലൈൻ-ആദ്യം സൃഷ്ടിപരമായ ആസ്തി മാനേജർ ആണ്, ഇത് Tauri, React, Rust ഉപയോഗിച്ച് നിർമ്മിച്ചതാണ്. പ്രകടനം അല്ലെങ്കിൽ സ്വകാര്യത വിട്ടുവീഴ്ച ചെയ്യാതെ അവരുടെ ഡിജിറ്റൽ ആസ്തികളിലേക്ക് വേഗത്തിലും വിശ്വസനീയമായും പ്രവേശനം ആവശ്യമുള്ള സൃഷ്ടിപരമായ പ്രൊഫഷണലുകൾക്കായി രൂപകൽപ്പന ചെയ്തിരിക്കുന്നു.

### എന്തുകൊണ്ട് Evoury?

- **ഓഫ്‌ലൈൻ-ആദ്യം**: നിങ്ങളുടെ ആസ്തികൾ നിങ്ങളുടെ മെഷീനിൽ തുടരുന്നു. ക്ലൗഡ് ആശ്രിതത്വം ഇല്ല.
- **മിന്നൽ വേഗത**: നിങ്ങളുടെ ലൈബ്രറിയുമായി സ്കെയിൽ ചെയ്യുന്ന പ്രകടനത്തിനായി Rust ഉപയോഗിച്ച് നിർമ്മിച്ചത്.
- **മൊഡുലർ ആർക്കിടെക്ചർ**: പരമാവധി വഴക്കത്തിനായി 40+ പ്രത്യേക ക്രേറ്റുകൾ.
- **സുന്ദരമായ UI**: React, Tailwind CSS ഉപയോഗിച്ച് നിർമ്മിച്ച ആധുനിക, പ്രതികരണശേഷിയുള്ള ഇന്റർഫേസ്.

## സവിശേഷതകൾ

### കോർ എഞ്ചിൻ

- **മൾട്ടി-ഫോർമാറ്റ് സപ്പോർട്ട്**: ചിത്രങ്ങൾ, വീഡിയോകൾ, 3D മോഡലുകൾ, ഓഡിയോ, ഡോക്യുമെന്റുകൾ എന്നിവയും കൂടുതലും
- **സ്മാർട്ട് പെയറിംഗ്**: ബന്ധപ്പെട്ട ഫയലുകൾ സ്വയമേവ ഗ്രൂപ്പ് ചെയ്യുന്നു
- **ആസ്തി സ്റ്റേറ്റ് മെഷീൻ**: കണ്ടെത്തൽ മുതൽ ആർക്കൈവൽ വരെ ആസ്തികൾ ട്രാക്ക് ചെയ്യുന്നു
- **ഇവന്റ്-ഡ്രിവൻ ആർക്കിടെക്ചർ**: ഇവന്റ് ബസ് വഴി വേർപെടുത്തിയ ആശയവിനിമയം

### ലൈബ്രറി മാനേജ്മെന്റ്

- **വിപുലമായ സ്കാനർ**: പൂർണ്ണ, ഇൻക്രിമെന്റൽ, ഫോൾഡർ-സ്പെസിഫിക്, ബാക്ക്‌ഗ്രൗണ്ട് സ്കാനിംഗ് മോഡുകൾ
- **ഫയൽസിസ്റ്റം വാച്ചർ**: മാനുവൽ റീഫ്രഷ് ഇല്ലാതെ റിയൽ-ടൈം സിംക്
- **മെറ്റാഡേറ്റ പൈപ്പ്ലൈൻ**: സ്വയമേവയുള്ള എക്സ്ട്രാക്ഷൻ, നോർമലൈസേഷൻ, വാലിഡേഷൻ, കാഷിംഗ്
- **ഡ്യൂപ്ലിക്കേറ്റ് ഡിറ്റക്ഷൻ**: SHA256, പെർസെപ്ഷ്വൽ ഹാഷ്, മെറ്റാഡേറ്റ അടിസ്ഥാനത്തിലുള്ള

### തിരച്ചിലും സംഘാടനവും

- **സ്ഥിരമായ തിരച്ചിൽ സൂചിക**: FTS5 ഉപയോഗിച്ച് മിന്നൽ വേഗത്തിലുള്ള പൂർണ്ണ-ടെക്സ്റ്റ് തിരച്ചിൽ
- **സ്മാർട്ട് ശേഖരങ്ങൾ**: നിയമ-അടിസ്ഥാനത്തിലുള്ള സ്വയമേവ അപ്ഡേറ്റ് ചെയ്യുന്ന ശേഖരങ്ങൾ
- **വിപുലമായ ക്വറി ഭാഷ**: ടൈപ്പ്, ടാഗ്, റേറ്റിംഗ്, തീയതി, ക്യാമറ എന്നിവ അടിസ്ഥാനമാക്കിയുള്ള ഫിൽട്ടറുകൾ
- **തിരച്ചിൽ പ്രൊഫൈലുകൾ**: തിരച്ചിൽ കോൺഫിഗറേഷനുകൾ സേവ് ചെയ്ത് മാറ്റാം

### വർക്ക്‌സ്പേസ് സിസ്റ്റം

- **സ്ഥിരമായ വർക്ക്‌സ്പേസുകൾ**: മുഴുവൻ സെഷൻ സ്റ്റേറ്റും ഓർക്കുന്നു
- **ബഹു വർക്ക്‌സ്പേസുകൾ**: വ്യത്യസ്ത പ്രോജക്റ്റ് സന്ദർഭങ്ങൾ തമ്മിൽ മാറ്റാം
- **വർക്ക്‌സ്റ്റേഷനുകൾ**: ഉപകരണങ്ങൾ, ഷോർട്ട്‌കട്ടുകൾ, തീമുകൾ എന്നിവയോടെ മുൻകൂട്ടി കോൺഫിഗർ ചെയ്ത ലേഔട്ടുകൾ
- **ഡോക്ക് ചെയ്യാവുന്ന പാനലുകൾ**: പൂർണ്ണമായും ഇഷ്ടാനുസൃതമാക്കാവുന്ന ലേഔട്ട് എഞ്ചിൻ

### ആരോഗ്യവും പരിപാലനവും

- **ആരോഗ്യ എഞ്ചിൻ**: ഫയൽസിസ്റ്റം, ഡാറ്റാബേസ്, കാഷ്, മെറ്റാഡേറ്റ എന്നിവയുടെ സമഗ്രത പരിശോധിക്കുന്നു
- **സ്വയമേവയുള്ള അറ്റകുറ്റപ്പണി**: കണ്ടെത്തിയ പ്രശ്നങ്ങൾക്ക് ഒരൊറ്റ ക്ലിക്ക് അറ്റകുറ്റപ്പണി
- **സെഷൻ റിക്കവറി**: അപ്രതീക്ഷിത ഷട്ട്‌ഡൗണുകൾക്ക് ശേഷം വർക്ക്‌സ്പേസ് പുനഃസ്ഥാപിക്കുന്നു
- **സ്ലീപ് മോഡ്**: നിഷ്ക്രിയ സമയത്ത് ന്യൂനതമ വിഭവ ഉപയോഗം

## ഇൻസ്റ്റലേഷൻ

### മുൻവ്യവസ്ഥകൾ

- [Rust](https://www.rust-lang.org/tools/install) (ഏറ്റവും പുതിയ സ്ഥിര പതിപ്പ്)
- [Node.js](https://nodejs.org/) (v18 അല്ലെങ്കിൽ അതിലധികം)
- [pnpm](https://pnpm.io/) (v8 അല്ലെങ്കിൽ അതിലധികം)

### ഡൗൺലോഡ്

[Releases](https://github.com/mh3nj/evoury/releases) പേജിൽ നിന്ന് ഏറ്റവും പുതിയ പതിപ്പ് ഡൗൺലോഡ് ചെയ്യുക.

### സോഴ്സിൽ നിന്ന് ബിൽഡ്

```bash
# റെപ്പോസിറ്ററി ക്ലോൺ ചെയ്യുക
git clone https://github.com/mh3nj/evoury.git
cd evoury

# ആശ്രിതത്വങ്ങൾ ഇൻസ്റ്റാൾ ചെയ്യുക
pnpm install

# വികസന സേവക ആരംഭിക്കുക
pnpm tauri dev

# ഉത്പാദനത്തിനായി ബിൽഡ് ചെയ്യുക
pnpm tauri build
```

## വികസനം

### ലഭ്യമായ കമാൻഡുകൾ

```bash
# വികസനം
pnpm dev              # Vite വികസന സേവക ആരംഭിക്കുക
pnpm tauri dev        # വികസന മോഡിൽ Tauri ആരംഭിക്കുക

# ബിൽഡ്
pnpm build            # ഫ്രണ്ട്‌എൻഡ് ബിൽഡ് ചെയ്യുക
pnpm tauri build      # ഉത്പാദനത്തിനായി Tauri ആപ്പ് ബിൽഡ് ചെയ്യുക

# ടെസ്റ്റുകൾ
pnpm test             # ഫ്രണ്ട്‌എൻഡ് ടെസ്റ്റുകൾ നടത്തുക
cargo test            # Rust ടെസ്റ്റുകൾ നടത്തുക

# ലിന്റ്
pnpm lint             # ESLint നടത്തുക
cargo clippy          # Clippy നടത്തുക

# ഫോർമാറ്റിംഗ്
pnpm format           # ഫ്രണ്ട്‌എൻഡ് കോഡ് ഫോർമാറ്റ് ചെയ്യുക
cargo fmt             # Rust കോഡ് ഫോർമാറ്റ് ചെയ്യുക
```

## ടെക് സ്റ്റാക്ക്

### ബാക്ക്‌എൻഡ്

- **Rust** - സിസ്റ്റം പ്രോഗ്രാമിംഗ് ഭാഷ
- **Tauri** - ഡെസ്ക്‌ടോപ്പ് ആപ്പ് ഫ്രെയിംവർക്ക്
- **SQLite** - ലോക്കൽ ഡാറ്റാബേസ്
- **Crossbeam** - സമാന്തര പ്രോഗ്രാമിംഗ് പ്രാഥമികങ്ങൾ

### ഫ്രണ്ട്‌എൻഡ്

- **React** - UI ലൈബ്രറി
- **TypeScript** - ടൈപ്പ്-സേഫ് JavaScript
- **Tailwind CSS** - യൂട്ടിലിറ്റി-ഫസ്റ്റ് CSS ഫ്രെയിംവർക്ക്
- **Zustand** - സ്റ്റേറ്റ് മാനേജ്മെന്റ്
- **Vite** - ബിൽഡ് ടൂൾ, വികസന സേവക
